This sprint packages a Kaggle-ready validation track for Northstar V4 so you can test PatchTST, TFT, and iTransformer against the updated research feature matrix without touching the Mac-side runners. Run the flow in this order: export data with `scripts/kaggle/export_kaggle_data.py`, upload it with `scripts/kaggle/upload_to_kaggle.sh`, then execute `nb_01_patchtst.ipynb`, `nb_02_tft.ipynb`, and `nb_03_itransformer.ipynb` in parallel on Kaggle before finishing with `nb_04_results_aggregator.ipynb`.
