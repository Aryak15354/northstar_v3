[`archive/GEN7_INTERFACE_RULE.md`](../archive/GEN7_INTERFACE_RULE.md).

freeze time (2026-07-25). When later work changes that, the change is recorded here — citing the
permanent ID(s) affected, stating what differs, and leaving the archived text, status and confidence
untouched.

Addendum numbers are sequential and never reused, even if an addendum is itself later superseded.

## How to read the archive after these

1. Read the archived finding by permanent ID, as written.
2. Check this index for that ID.
3. If an addendum exists, the archived statement is still what was concluded at freeze; the addendum
   is what is believed now.

Full evidence for every addendum is in `results/gen10/`, with the programme synthesis at
[`results/gen10/GEN10_SYNTHESIS.md`](../results/gen10/GEN10_SYNTHESIS.md) and the pre-registrations at
[`GEN10_REMEDIATION_CHARTER.md`](../GEN10_REMEDIATION_CHARTER.md).
